> [!IMPORTANT]
> **Ports Launcher 本身不提供任何游戏文件、ROM、ISO 或其他受版权保护的资源。** 目录中的每个条目只会安装重编译或源码移植的*代码*，也就是各项目仓库自行发布的开源构建。条目所需的原版游戏数据须由你从合法获得的副本中自行提供；Ports Launcher 绝不会打包、下载、托管或链接这些数据。

一款轻量级的非官方游戏移植库与安装器：浏览目录，直接从 GitHub/GitLab 发布版（或直接下载链接）安装，然后启动，并在同一个窗口中让一切保持最新。使用 Rust 和 [Slint](https://slint.dev) 编写，全程支持键盘*和*手柄操作，无需另外安装任何软件（可执行文件旁附带一个精简版 7-Zip，用于解压移植的发布包）。

想让你的项目加入目录？请在 [Discord 服务器](https://ports-launcher.nyaruhodo.com/discord)上提出。

## 功能

- 基于目录（`catalog.json`）的游戏库，另有本地目录（`catalog.local.json`）用于存放你自行管理的移植
- 一键安装：自动下载适合你的系统架构的发布文件
- 默认自动更新：可在信息面板中通过**更新**按钮按移植关闭
- Ports Launcher 也会检查自身的新版本：有新构建时，页脚的 **GitHub** 按钮会变为**更新**；可在 ◯ **设置**中关闭更新或立即强制更新
- 每个移植都有信息面板：已安装的版本/标签、设置说明，以及官网、模组页面、安装文件夹和存档文件夹的一键链接；说明文字可以选择和复制
- 信息面板中的**选择版本**按钮：从最近的 GitHub/GitLab 发布版中选择并安装，也可以立即强制更新；同时会关闭该移植的自动更新，可随时重新开启
- 信息面板中的**安装额外文件**按钮：在可用时安装该移植的可选预设配置，并覆盖现有配置
- 一键卸载：如果存档位于移植自身的文件夹内，则会保留；封面只下载一次，之后缓存在本地
- ◯ **设置**中的**备份存档**按钮：一键将所有移植的存档导出到带日期的 `.zip`（两种机制见[游戏存档](#游戏存档)）
- 游戏时长统计：每个移植的累计游戏时长和上次游玩日期都显示在信息面板中，可通过**重置游戏时长**按钮重新计数
- 目录会优先列出你最近游玩的移植
- ◯ **设置**中的 **Discord Rich Presence** 开关（默认关闭）：在 Discord 个人资料中显示你正在玩的游戏
- 全屏“库”模式（`Alt+Enter`）：以卡片网格显示所有*已安装*的移植，类似 Steam 大屏幕模式
- 整个应用（包括所有对话框）都支持手柄（XInput）和键盘（方向键、Enter、Escape）操作：浏览、安装、启动、打开信息、选择文件或可执行文件以及返回，只用手柄或只用键盘都能完成
- 100 多款现成的配色主题：可在应用内的 ◯ **设置**中实时预览并切换
- 系统托盘图标：关闭主窗口会将其收入托盘，而不是退出。左键单击图标可恢复窗口；右键单击可打开菜单，其中包括最近游玩的 5 款游戏（直接**运行**）、**设置**和**退出**。标题栏中 ◯ **设置**旁还有专用的最小化按钮

## 键盘和手柄

| 按键 ⌨️ | 按钮 🎮 | 操作 |
|---|---|---|
| 输入文字 | — | 实时模糊筛选目录 |
| `↑` / `↓` 或 `Ctrl+W` / `Ctrl+S` | 方向键 / 左摇杆 | 上下移动选择 |
| `←` / `→` 或 `Ctrl+A` / `Ctrl+D` | 方向键 / 左摇杆 | 跳转一页（窗口列表中为 10 行）/ 一列（库网格） |
| `Enter` | `A` 或 `Start` | 所选移植未安装时进行安装，否则启动 |
| `Shift+Enter` | — | 在资源管理器中打开所选移植的安装文件夹 |
| — | `X` | 打开所选移植的信息面板 |
| — | `Y` | 打开 ◯ **设置** |
| `Alt+Enter` | `Back` | 切换全屏库模式 |
| `Ctrl+1`...`Ctrl+9` / `Ctrl+0` | — | 将启动器窗口调整为屏幕大小的 10%...90% / 100%（仅限窗口模式） |
| `Ctrl+-` / `Ctrl+=` | — | 将边框减小 / 增大 1 像素（仅限窗口模式） |
| `Escape` | `B` | 如有打开的对话框则关闭；如处于库模式则退出；否则关闭启动器（`B` 仅用于退出对话框） |

插入 XInput 手柄（Xbox 类型）后即可使用，无需设置，还能与键盘同时使用。主窗口中的搜索框始终保持焦点，上述按键和按钮都直接在那里处理。上层的对话框（信息、◯ **设置**、安装进度、文件或可执行文件选择等）则有各自的焦点：同样的按键和按钮用于在对话框内移动选择，`Enter`/`A` 执行，`Escape`/`B` 关闭（无法中断的安装进度对话框除外）。鼠标与键盘/手柄的选择始终同步，无论如何移动，都只有一项高亮。

你还可以按标签筛选搜索结果。几个实用的标签：`free` 表示**合法**免费的游戏（开源或免费软件），`quality` 表示公认特别精良的移植，`online` 表示支持在线多人游戏的移植。目录中的其他标签用法相同，包括原平台（`n64`、`ps1`、`snes`、`360`、`gc` 等）、类型（`platformer`、`rpg`、`fighting` 等）、`multiplayer`、`multilingual` 等。

## 库模式

`Alt+Enter` 会切换到全屏网格，显示你当前*已安装*的所有移植，类似 Steam 大屏幕模式的游戏库。尚未安装的移植只显示在窗口列表中，不会出现在库模式里。按 `Escape`（或再次按 `Alt+Enter`）返回窗口视图。

## 信息面板

选择一个移植并打开其**信息**面板（点击按钮，或按手柄上的 `X`），可查看已安装的版本/标签和设置说明（文字可选择和复制），并有官网、模组页面、安装文件夹和存档文件夹的一键链接。对于有第二个独立存档位置（`save2`）的移植，还有**存档文件夹2**按钮。尚不存在的项目（未安装、游戏尚未创建存档，或移植没有第二个存档位置）对应的按钮会被禁用。说明文字过长时，可用 `↑`/`↓`（或手柄的方向键/摇杆）滚动；用 `←`/`→` 在按钮之间移动，用 `Enter`/`A` 执行高亮的按钮。

版本文字旁的**选择版本**按钮（仅限 GitHub/GitLab 移植）会获取最近的发布版，让你安装其中任意一个，而不必总是安装最新版。当最新发布版没有适合你的平台的构建，或者你想回退时，这会很方便。它总是从 GitHub/GitLab 重新获取，所以从列表中选择最新版也能立即强制更新；以这种方式安装特定版本还会关闭该移植的自动更新，因此下次**运行**时不会被悄悄替换为最新发布版。

对于已安装的移植，这里还会显示**更新：开/关**、**常用可执行文件**、**上次游玩**和**游戏时长**，每项的按钮都紧贴在版本/状态文字下方。你可以按移植开关自动更新，选择**运行**时直接启动的可执行文件而不必每次询问，或重置该移植的游戏时长。关闭了自动更新的移植，会在主列表的**运行**旁显示一个带删除线的黄色**更新**按钮，提醒你它不会自行更新。

旁边的**安装额外文件**按钮会在可用时安装该移植的可选预设配置，并覆盖现有配置。**运行**或**安装**绝不会自动拉取这些文件，只能由你在这里选择安装。

## 游戏存档

Ports Launcher 有两种独立的存档机制，都基于 `catalog.json` 的 `save`/`save2` 字段，并保存在可执行文件旁的 `Saves Backup` 文件夹中：

**自动保留**（卸载/重新安装）：卸载存档位于安装文件夹内的移植时，在删除文件夹其余内容之前，存档会被复制到 `Saves Backup/Pending Restore/<folder>/save_folder/`（第二个存档位置为 `.../save_folder2/`）。之后再次安装同一移植时，存档会被移回原位，并删除这份临时副本。位于安装文件夹之外（例如 `%APPDATA%` 下）的存档完全不受卸载影响。`Pending Restore` 不是历史记录：每个移植和字段只有一个位置，每次卸载都会覆盖。如果存档在重新安装途中似乎不见了，或者安装中断需要手动恢复，可以来这里查找。

**手动导出**（**备份存档**按钮，见下方的 ◯ [设置](#设置)）：按需将整个目录中所有移植的存档（无论是否已安装，也无论位于外部还是本地）导出到 `Saves Backup/Global Backups/<date>.zip`。同一天再次运行时，会用当前状态覆盖当天的 `.zip`，而不是合并，因此之后卸载的移植不会残留其中。每个日期都是一份干净的快照，与 `Pending Restore` 不同，这才是真正的历史记录。

## 设置

从标题栏的 **◯** 按钮打开。菜单包括**主题**、**语言**、**库**、**工具**、**备份存档**、**检查更新**、**公告**、**Discord Rich Presence**、**Custom Rich Presence**、**文件**和**强制更新**。

- **主题**、**语言**和**工具**都会打开同一种支持实时模糊搜索的选择器。对于主题，移动选择（鼠标悬停，或 `↑`/`↓`/手柄摇杆）会立即在整个应用中预览；确认后写入 `themes.json`，不确认就关闭（`Escape`）则恢复之前的主题。语言在选择后立即切换，无需重启。
- **工具**列出了一些实用的外部工具，用于准备移植所需的文件（压缩工具、补丁工具、光盘提取工具、转换工具等），可按名称或标签（`patcher`、`psp`、`360` 等）搜索。选择后会在浏览器中打开其页面，由你自行下载和设置。列表来自 `catalog.json` 的 `"tools"` 部分，因此会随目录更新，并包含你添加到 `catalog.local.json` 的工具。
- **文件**可打开 `catalog.json`、`catalog.local.json`、`state.json` 和 `themes.json` 的快捷方式；文件尚不存在时不会有任何反应。
- **库**会直接在资源管理器中打开该文件夹。
- **备份存档**会将整个目录的存档导出到带日期的 `.zip`（见上方的[游戏存档](#游戏存档)），复制时会显示进度窗口。
- **检查更新**可直接在菜单中开关，一次关闭所有更新检查（启动器自身的检查，以及**运行**时对已安装移植的检查），适合想手动更新一切的用户。
- **强制更新**会立即运行启动器的更新程序，不会先检查是否确实有新构建，适合不想等待定期检查（或已关闭上述检查）的用户。
- **Discord Rich Presence** 可直接在菜单中开关，默认关闭：在 Discord 状态中显示你正在玩的游戏，并在关闭游戏时立即清除。
- **Custom Rich Presence** 可直接在菜单中开关，默认关闭：在 Ports Launcher 运行期间改为显示你自己的状态，并附带已用时间和 **Ports Launcher** 按钮；开启时，游戏不再显示各自的状态。文字和图标在 `state.json` 中设置（请在关闭 Ports Launcher 后编辑，否则修改会被覆盖）：

  ```json
  "custom_presence": {
    "enabled": true,
    "text": "你的文字",
    "icon": "https://...（公开的图片网址，可选）"
  }
  ```

  没有 `text` 时不起作用，游戏照常显示各自的状态。**Discord Rich Presence** 也必须开启。

- **公告**可直接在菜单中开关，默认开启：在页脚按钮左侧的横幅中显示维护者发布的消息，仅限窗口模式。文字只有在横幅中放不下时才会滚动；如果消息带有链接，点击横幅会在浏览器中打开。关闭后，Ports Launcher 完全不会获取公告。

## 配置

### `catalog.json`

主目录。不建议手动编辑：目录更新时它会被整体替换，所以你在这里添加的内容会在下次刷新时被悄悄覆盖。如果要永久添加自己的移植，请使用下面的 [`catalog.local.json`](#cataloglocaljson)。

### `catalog.local.json`

你自己的目录，位于 `catalog.json` 旁边，用于你自行管理而不通过 Ports Launcher 安装的移植：在 `Library/` 下创建文件夹，手动放入游戏文件，它就会像其他移植一样显示（可以运行，有信息面板，安装后也会出现在库模式中）。条目格式与 `catalog.json` 相同，只是这里不使用 `source`：请省略它或留空。由于此文件单独存放，维护者发布的新版 `catalog.json` 替换旧版时，不会影响你在这里添加的内容。

如果 `folder` 与 `catalog.json` 中的条目相同，官方条目会被你的本地条目替换。本地移植的**卸载**按钮行为也不同：它不会删除任何内容，而是在资源管理器中打开该移植的文件夹，让你完全掌控这些并非由 Ports Launcher 下载的文件。

你也可以用同样的方式，在 `"tools"` 部分（`name`、`source` 和可选的 `tags`）向**工具**列表添加自己的条目。如果工具的 `name` 与 `catalog.json` 中的工具相同，则会将其替换。

如果此文件不存在，Ports Launcher 会创建它，并附上已禁用的移植和工具示例（`"name"` 设为 `null`，Ports Launcher 会跳过它们）。复制一个示例并填入真实的值，它就会成为真正的条目。旧版本的 `ports.local.json` 会被自动重命名。

### `state.json`

Ports Launcher 的配置文件，包含已安装的版本和游戏时长、窗口状态、显示偏好以及更新检查时间，会在你使用应用时自动写入。

你也可以手动添加 `"github_token"`/`"gitlab_token"` 键，以提高更新检查所用的 GitHub/GitLab API 速率限制。令牌会以**明文**保存，所以切勿分享此文件、将其上传到任何地方，或在直播和屏幕共享时让它显示出来。

如需从其他地址获取目录、主题或公告，请填写 `"catalog_url"`、`"themes_url"` 或 `"announcement_url"` 键（请在关闭 Ports Launcher 后编辑，否则修改会被覆盖）。链接必须以 `https://` 开头。留空时，Ports Launcher 使用默认地址。
