> [!IMPORTANT]
> **Ports Launcher 自体は、ゲームファイル、ROM、ISO、その他の著作権で保護されたアセットを一切配布していません。** カタログの各エントリがインストールするのは、リコンパイルやソースポートの*コード*、つまり各プロジェクトのリポジトリが公開しているオープンソースのビルドのみです。必要なオリジナルのゲームデータは、合法的に入手したご自身のコピーからご用意ください。Ports Launcher がそのデータを同梱、ダウンロード、ホスト、またはリンクすることはありません。

非公式ゲームポート向けの軽量なライブラリ兼インストーラーです。カタログを閲覧し、GitHub/GitLab のリリース（または直接ダウンロードリンク）からそのままインストールして起動でき、すべてを 1 つのウィンドウで最新の状態に保てます。Rust と [Slint](https://slint.dev) で作られており、キーボードとゲームパッドのどちらでも全画面を操作できます。別途インストールするものはありません（ポートのリリースを展開するための最小構成の 7-Zip が実行ファイルと一緒に同梱されています）。

ご自身のプロジェクトをカタログに追加したい場合は、[Discord サーバー](https://ports-launcher.nyaruhodo.com/discord)でお問い合わせください。

## 機能

- カタログ（`catalog.json`）をもとにしたライブラリと、自分で管理するポート用のローカルカタログ（`catalog.local.json`）
- ワンクリックでインストール：お使いのアーキテクチャに合ったリリースファイルを自動でダウンロード
- 自動更新がデフォルトで有効：情報パネルの**アップデート**ボタンからポートごとにオフにできます
- Ports Launcher 自身の新しいバージョンも確認します：新しいビルドが出ると、フッターの **GitHub** ボタンが**アップデート**に変わります。◯ **設定**から更新を無効にしたり、すぐに強制したりできます
- ポートごとの情報パネル：インストール済みのバージョン/タグ、セットアップ手順、ウェブサイト、MOD ページ、インストールフォルダ、セーブフォルダへのワンクリックリンク。手順のテキストは選択とコピーが可能です
- 情報パネルの**バージョンを選択**ボタン：最近の GitHub/GitLab リリースから選んでインストールしたり、すぐに更新を強制したりできます。そのポートの自動更新もオフになりますが、いつでも再度オンにできます
- 情報パネルの**追加ファイルをインストール**ボタン：利用可能な場合に、ポート用のオプションのプリセット設定をインストールします。既存の設定は上書きされます
- ワンクリックでアンインストール：セーブデータがポートのフォルダ内にある場合は保持されます。ボックスアートは一度ダウンロードされると、以降はローカルにキャッシュされます
- ◯ **設定**の**セーブのバックアップ**ボタン：全ポートのセーブを、日付入りの `.zip` にワンクリックで書き出します（2 つの仕組みについては[ゲームのセーブデータ](#ゲームのセーブデータ)を参照）
- プレイ時間の記録：各ポートの累計プレイ時間と最終プレイ日が情報パネルに表示され、**プレイ時間をリセット**ボタンでカウンターをやり直せます
- カタログでは、最近プレイしたポートが先頭に表示されます
- ◯ **設定**の **Discord Rich Presence** スイッチ（デフォルトはオフ）：プレイ中のゲームを Discord プロフィールに表示します
- フルスクリーンの「ライブラリ」モード（`Alt+Enter`）：*インストール済み*のポートを、Steam Big Picture のようにカードのグリッドで表示します
- ゲームパッド（XInput）とキーボード（矢印キー、Enter、Escape）で、すべてのダイアログを含むアプリ全体を操作可能：閲覧、インストール、起動、情報の表示、ファイルや実行ファイルの選択、戻る操作が、コントローラーだけでもキーボードだけでも行えます
- 100 種類以上のカラーテーマ：アプリ内の ◯ **設定**から即座にプレビューしながら切り替えられます
- システムトレイアイコン：メインウィンドウを閉じると、終了せずにトレイに格納されます。アイコンを左クリックすると再表示され、右クリックすると最近プレイした 5 つのゲーム（そのまま**プレイ**を実行）、**設定**、**終了**のメニューが開きます。タイトルバーの ◯ **設定**の隣には、専用の最小化ボタンもあります

## キーボードとゲームパッド

| キー ⌨️ | ボタン 🎮 | 操作 |
|---|---|---|
| 文字入力 | — | カタログをあいまい検索で絞り込み |
| `↑` / `↓` または `Ctrl+W` / `Ctrl+S` | 十字キー / 左スティック | 選択を上下に移動 |
| `←` / `→` または `Ctrl+A` / `Ctrl+D` | 十字キー / 左スティック | 1 ページ（ウィンドウのリストで 10 行）/ 1 列（ライブラリのグリッド）移動 |
| `Enter` | `A` または `Start` | 選択したポートが未インストールならインストールし、インストール済みなら起動 |
| `Shift+Enter` | — | 選択したポートのインストールフォルダをエクスプローラーで開く |
| — | `X` | 選択したポートの情報パネルを開く |
| — | `Y` | ◯ **設定**を開く |
| `Alt+Enter` | `Back` | フルスクリーンのライブラリモードを切り替え |
| `Ctrl+1`...`Ctrl+9` / `Ctrl+0` | — | ランチャーのウィンドウを画面サイズの 10%〜90% / 100% に変更（ウィンドウモードのみ） |
| `Ctrl+-` / `Ctrl+=` | — | 枠線を 1px 細く / 太くする（ウィンドウモードのみ） |
| `Escape` | `B` | ダイアログが開いていれば閉じ、ライブラリモード中なら戻り、それ以外はランチャーを閉じる（`B` はダイアログから戻る操作のみ） |

XInput コントローラー（Xbox タイプ）を接続すれば、設定なしですぐにキーボードと併用できます。メインウィンドウでは検索ボックスが常にフォーカスを保ち、上記のキーやボタンはすべてそこで直接処理されます。手前に開いたダイアログ（情報、◯ **設定**、インストールの進行状況、ファイルや実行ファイルの選択など）は専用のフォーカスを持ちます。同じキーやボタンでダイアログ内の選択を移動し、`Enter`/`A` で実行し、`Escape`/`B` で閉じます（中断できないインストールの進行状況ダイアログを除く）。マウスとキーボード/コントローラーの選択は常に同期し、ハイライトされる項目は常に 1 つだけです。

検索はタグでも絞り込めます。覚えておくと便利なタグには、**合法的に**無料のゲーム（オープンソースまたはフリーウェア）を示す `free`、特に完成度が高いとされるポートを示す `quality`、オンラインマルチプレイヤー対応のポートを示す `online` があります。その他のタグも同様に使えます。元のプラットフォーム（`n64`、`ps1`、`snes`、`360`、`gc` など）、ジャンル（`platformer`、`rpg`、`fighting` など）、`multiplayer`、`multilingual` などです。

## ライブラリモード

`Alt+Enter` を押すと、現在*インストール済み*のポートをすべて表示するフルスクリーンのグリッドに切り替わります。Steam の Big Picture のライブラリのようなものです。未インストールのポートはウィンドウのリストにのみ表示され、ライブラリモードには表示されません。`Escape`（またはもう一度 `Alt+Enter`）でウィンドウ表示に戻ります。

## 情報パネル

ポートを選択して**情報**パネルを開くと（ボタン、またはコントローラーの `X`）、インストール済みのバージョン/タグ、セットアップ手順（選択とコピーが可能なテキスト）のほか、ウェブサイト、MOD ページ、インストールフォルダ、セーブフォルダへのワンクリックリンクが表示されます。独立した 2 つ目のセーブ先（`save2`）を持つポートには、**セーブフォルダ2** ボタンもあります。まだ存在しない項目（未インストール、ゲームがセーブをまだ作成していない、2 つ目のセーブ先がないなど）のボタンは無効になります。手順のテキストが長い場合は `↑`/`↓`（またはコントローラーの十字キー/スティック）でスクロールし、`←`/`→` でボタン間を移動して、`Enter`/`A` でハイライトされたボタンを実行します。

バージョン表示の隣にある**バージョンを選択**ボタン（GitHub/GitLab のポートのみ）は、最近のリリースを取得し、常に最新版ではなく任意のバージョンをインストールできるようにします。最新のリリースにお使いのプラットフォーム向けのビルドがない場合や、以前のバージョンに戻したい場合に便利です。常に GitHub/GitLab から新しく取得するため、一覧から最新版を選べば、すぐに更新を強制することもできます。この方法で特定のバージョンをインストールすると、そのポートの自動更新もオフになり、次の**プレイ**で最新リリースに勝手に置き換えられることはありません。

インストール済みのポートには、**更新：オン/オフ**、**お気に入りの実行ファイル**、**最終プレイ日**、**プレイ時間**も表示され、それぞれのボタンがバージョン/ステータス表示のすぐ下にあります。ポートごとに自動更新を切り替えたり、毎回確認せずに**プレイ**で直接起動する実行ファイルを選んだり、そのポートのプレイ時間をリセットしたりできます。自動更新がオフのポートには、自動で更新されないことを示すため、メインリストの**プレイ**の隣に取り消し線付きの黄色い**アップデート**ボタンが表示されます。

その隣の**追加ファイルをインストール**ボタンは、利用可能な場合にポート用のオプションのプリセット設定をインストールし、既存の設定を上書きします。**プレイ**や**インストール**で自動的に導入されることはなく、常にここから任意で行います。

## ゲームのセーブデータ

Ports Launcher には 2 つの独立したセーブの仕組みがあります。どちらも `catalog.json` の `save`/`save2` フィールドに基づき、実行ファイルの隣の `Saves Backup` フォルダに保存されます。

**自動保持**（アンインストール/再インストール）：セーブがインストールフォルダ内にあるポートをアンインストールすると、フォルダの残りが削除される直前に、セーブが `Saves Backup/Pending Restore/<folder>/save_folder/`（2 つ目のセーブ先は `.../save_folder2/`）にコピーされます。後で同じポートをインストールすると、セーブが元の場所に戻され、この一時コピーは削除されます。インストールフォルダの外（`%APPDATA%` など）にあるセーブは、アンインストールの影響を一切受けません。`Pending Restore` は履歴ではなく、ポートとフィールドごとに 1 つの枠しかなく、アンインストールのたびに上書きされます。再インストール中にセーブが消えたように見える場合や、インストールが中断されて手動で復元する必要がある場合は、ここを確認してください。

**手動書き出し**（**セーブのバックアップ**ボタン、下記の ◯ [設定](#設定)を参照）：必要なときに、カタログ全体の全ポートのセーブ（インストールの有無、外部かローカルかを問わず）を `Saves Backup/Global Backups/<date>.zip` に書き出します。同じ日にもう一度実行すると、統合せずにその日の `.zip` を現在の状態で上書きするため、その後アンインストールしたポートは残りません。各日付がそれぞれ独立したスナップショットとなり、`Pending Restore` とは異なり、本当の履歴になります。

## 設定

タイトルバーの **◯** ボタンから開きます。メニューには**テーマ**、**言語**、**ライブラリ**、**ツール**、**セーブのバックアップ**、**更新チェック**、**お知らせ**、**Discord Rich Presence**、**Custom Rich Presence**、**ファイル**、**強制更新**があります。

- **テーマ**、**言語**、**ツール**は、いずれも同じ形式の、あいまい検索ができる選択画面を開きます。テーマでは、選択を移動する（マウスを合わせる、または `↑`/`↓`/コントローラーのスティック）とアプリ全体に即座にプレビューされます。確定すると `themes.json` に書き込まれ、確定せずに閉じる（`Escape`）と元のテーマに戻ります。言語は選択するとすぐに切り替わり、再起動は不要です。
- **ツール**は、ポートに必要なファイルを準備するための便利な外部ツール（アーカイバ、パッチャー、ディスク抽出ツール、コンバーターなど）の一覧で、名前やタグ（`patcher`、`psp`、`360` など）で検索できます。選択するとブラウザでそのページが開くので、ダウンロードと設定はご自身で行ってください。一覧は `catalog.json` の `"tools"` セクションから取得されるため、カタログの更新とともに最新の状態に保たれます。`catalog.local.json` に追加したツールも表示されます。
- **ファイル**は、`catalog.json`、`catalog.local.json`、`state.json`、`themes.json` へのショートカットを開きます。ファイルがまだ存在しない場合は何も起こりません。
- **ライブラリ**は、そのフォルダをエクスプローラーで直接開きます。
- **セーブのバックアップ**は、カタログ全体のセーブを日付入りの `.zip` に書き出します（上記の[ゲームのセーブデータ](#ゲームのセーブデータ)を参照）。コピー中は進行状況ウィンドウが表示されます。
- **更新チェック**は、メニュー内でオン/オフを切り替えます。ランチャー自身の確認と、**プレイ**時のインストール済みポートの確認をすべて一度にオフにできるので、すべて手動で更新したい方に向いています。
- **強制更新**は、新しいビルドがあるかどうかを確認せずに、ランチャーのアップデーターをすぐに実行します。定期的な確認を待ちたくない場合や、上記の確認をオフにしている場合にご利用ください。
- **Discord Rich Presence** は、メニュー内でオン/オフを切り替えます（デフォルトはオフ）。プレイ中のゲームを Discord のステータスに表示し、ゲームを閉じるとすぐに消えます。
- **Custom Rich Presence** は、メニュー内でオン/オフを切り替えます（デフォルトはオフ）。Ports Launcher の実行中は、代わりに独自のステータスを、経過時間と **Ports Launcher** ボタンとともに表示します。オンの間は、ゲームごとのプレゼンスは表示されません。テキストとアイコンは `state.json` で設定します（Ports Launcher を閉じた状態で編集してください。起動中の編集は上書きされます）。

  ```json
  "custom_presence": {
    "enabled": true,
    "text": "表示するテキスト",
    "icon": "https://... （公開された画像の URL、任意）"
  }
  ```

  `text` がない場合は何も起こらず、ゲームのプレゼンスが通常どおり表示されます。**Discord Rich Presence** もオンにする必要があります。

- **お知らせ**は、メニュー内でオン/オフを切り替えます（デフォルトはオン）。メンテナーからのメッセージを、フッターのボタンの左にあるバナーに表示します（ウィンドウモードのみ）。テキストはバナーに収まらない場合にのみスクロールし、メッセージにリンクがある場合は、バナーをクリックするとブラウザで開きます。オフの場合、Ports Launcher はメッセージを一切取得しません。

## 構成

### `catalog.json`

メインのカタログです。手動での編集は想定されていません。カタログの更新で丸ごと置き換えられるため、ここに追加した内容は次回の更新時に警告なく上書きされます。自分のポートを恒久的に追加するには、下記の [`catalog.local.json`](#cataloglocaljson) を使用してください。

### `catalog.local.json`

`catalog.json` の隣に置く独自のカタログです。Ports Launcher でインストールせず、自分で管理するポートに使います。`Library/` の下にフォルダを作成してゲームのファイルを手動で配置すると、他のポートと同じように表示されます（プレイ可能で、情報パネルがあり、インストール後はライブラリモードにも表示されます）。エントリの形式は `catalog.json` と同じですが、`source` は使用しません。省略するか、空にしてください。このファイルは別に保管されるため、`catalog.json` がメンテナーの新しいバージョンに置き換えられても、ここに追加した内容は影響を受けません。

`catalog.json` のエントリと `folder` が重複する場合は、公式のエントリがローカルのエントリに置き換えられます。ローカルのポートでは**アンインストール**ボタンの動作も異なります。何も削除せず、代わりにポートのフォルダをエクスプローラーで開くので、Ports Launcher がダウンロードしていないファイルは完全にご自身で管理できます。

同じように、`"tools"` セクション（`name`、`source`、任意の `tags`）で**ツール**の一覧に独自のエントリを追加できます。`catalog.json` のツールと `name` が同じ場合は、そのツールが置き換えられます。

このファイルが存在しない場合、Ports Launcher は無効化されたポートとツールの例（`"name"` が `null` のため Ports Launcher に無視されます）を含めて作成します。例をコピーして実際の値を入力すると、本当のエントリになります。古いバージョンの `ports.local.json` は自動的に名前が変更されます。

### `state.json`

Ports Launcher の設定ファイルです。インストール済みのバージョンやプレイ時間、ウィンドウの状態、表示設定、更新確認の日時が、アプリの使用中に自動で書き込まれます。

更新確認に使う GitHub/GitLab API のレート制限を緩和するために、`"github_token"`/`"gitlab_token"` キーを手動で追加することもできます。このトークンは**平文**で保存されるため、このファイルを共有したり、どこかにアップロードしたり、配信や画面共有で表示したりしないでください。

カタログ、テーマ、お知らせを別のアドレスから取得するには、`"catalog_url"`、`"themes_url"`、`"announcement_url"` キーを入力します（Ports Launcher を閉じた状態で編集してください。起動中の編集は上書きされます）。リンクは `https://` である必要があります。空の場合は、デフォルトのアドレスが使用されます。

## クレジット

- カタログのエントリで使用しているボックスアートを提供する [SteamGridDB](https://www.steamgriddb.com/)
- `catalog.json` に掲載されているリコンパイルやソースポートの作者の皆さん：多くの場合、何か月にもわたる無償のリバースエンジニアリングの成果であり、これなしには何も存在しませんでした
- [7-Zip](https://github.com/ip7z/7zip)：ポートのリリースアーカイブを展開するため、最小構成のコマンドライン版を Ports Launcher に同梱しています
